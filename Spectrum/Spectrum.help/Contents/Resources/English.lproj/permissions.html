Privacy & permissions

Spectrum needs operating-system permission only so it can hear audio. It does not record, store, or upload that audio, and it does not use Screen Recording to capture anything visual.

Spectrum does not record your screen. When you enable Spectrum in System Settings under Screen Recording, macOS is allowing the app to hear audio that other programs are playing. Spectrum uses that sound only to draw the live frequency spectrum.

Spectrum does not take screenshots, does not capture video, does not read the contents of windows, and does not keep a recording of the display. Apple uses the Screen Recording switch for this kind of audio access. There is no separate “system audio” switch in System Settings.

Which permission you need

What you want to analyze Permission System Settings location
Test Signal (sine, noise, sweep) None —
A microphone, USB mic, or audio interface Microphone Privacy & Security > Microphone
System Audio (everything playing on the Mac) Screen Recording (for audio only) Privacy & Security > Screen Recording
A single application’s output Screen Recording (for audio only) Privacy & Security > Screen Recording

Do not enable Spectrum under Accessibility. Spectrum does not need the Accessibility (control your Mac) permission. Granting that does not help audio capture. The relevant panes are Microphone and Screen Recording only.

Screen Recording permission, in detail

macOS protects the audio that applications send to the speakers. The setting that unlocks that audio is named Screen Recording, even when an app never looks at the screen.

If the permission is off, Spectrum still opens and test signals still work, but System Audio and application sources stay silent. The analyzer is running; it is simply not allowed to hear other programs.

What Spectrum does with the grant

  • Listens to the sound you selected (the Mac’s output, or one application)
  • Draws the live spectrum, peak hold, and input meters
  • Discards the audio after it has been analyzed — nothing is saved as a movie, screenshot, or sound file

What Spectrum does not do with the grant

  • Does not record the screen or any display
  • Does not capture window contents, the menu bar, or the pointer
  • Does not photograph the desktop
  • Does not use the permission to observe other apps visually
  • Does not send audio or video off the Mac

How to grant Screen Recording

  1. In Spectrum, open the Input menu and choose System Audio or a running application. macOS may show a prompt. Click Open System Settings if it offers that.
  2. Or choose Spectrum > Settings…, open the Audio tab, and under System Audio click Open System Settings or Request Access.
  3. In System Settings go to Privacy & Security > Screen Recording.
  4. Turn Spectrum on. If the list shows more than one Spectrum row, turn on each one you recognize, or turn them all on.
  5. Fully quit Spectrum (Spectrum > Quit Spectrum or Command-Q). Closing the window or hiding the app is not enough.
  6. Open Spectrum again, then select System Audio or the application. Play something on the Mac. You should see a live spectrum.

Quit and reopen after granting access

macOS applies Screen Recording permission when the app starts. If Spectrum was already running when you turned the switch on, it will not hear system or application audio until you quit and open it again.

If Screen Recording already shows Spectrum as allowed but the plot is still silent, quit Spectrum completely and open it from the Dock, Launchpad, or the Applications folder. Then choose System Audio or an application and play sound.

If System Settings lists more than one Spectrum, enable them, quit the app, and open Spectrum once more.

Microphone permission

Physical devices (Built-in Microphone, USB microphones, audio interfaces) use the standard Microphone permission. Spectrum asks for it when you select an Audio Input device. You can also open Spectrum > Settings… > Audio and click Request Access or Open System Settings.

Path: System Settings > Privacy & Security > Microphone, then enable Spectrum.

Microphone access is used only to read the selected hardware input for the spectrum display. Spectrum does not record the mic to a file and does not use the mic when you are on Test Signal, System Audio, or an application source.

Checking status inside Spectrum

The Audio tab in Settings shows the current Microphone status and whether Screen Recording is granted. If capture cannot start, the control bar shows an error and buttons to request access or open System Settings.
