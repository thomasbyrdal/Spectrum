Performance

These options are in Spectrum > Settings… > Performance. The status bar FPS value is the actual plot update rate, not the target.

Target FPS

30 or 60 frames per second requested for the spectrum view. Large FFTs may not reach 60; the FPS meter shows what is actually drawn.

Smoothing

When enabled, bar levels attack and release instead of jumping every hop. Higher attack and release coefficients follow the signal more quickly; lower values look more averaged. Use Low CPU preset if the machine is busy: fewer bars, smaller FFT, 50% overlap, 30 fps.

FFT overlap

50%, 75%, or 87.5%. Higher overlap updates the analyzer more often for a given FFT size, which looks smoother, at higher CPU cost. Hop size is also limited by the target frame rate so a huge FFT can still refresh in real time.

Stereo spectrum

Show stereo spectrum runs a separate FFT for the left and right channels. That is about twice the analyzer work of the mixed view. Use the Low CPU preset if the machine is busy.

Silent sources

If the selected input stops producing audio, Spectrum shows Stopped and pauses FFT work. The live bars clear and the peak-hold markers fall to the floor, then the plot stops updating (except when you resize the window). Capture stays connected so playback can resume immediately as Running.

CPU meter

The status bar CPU figure is this process’s usage relative to elapsed time (it can exceed 100% on multi-core Macs). It is display-only and is not sampled from the audio callback.
