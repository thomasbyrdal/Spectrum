Choosing an audio source

Use the Input menu on the control bar. A checkmark shows the current source. Spectrum always listens to one source at a time.

Test Signal

Generated inside the app. No microphone or Screen Recording permission is required. Use these to confirm the plot, FFT size, and meters before connecting live audio.

SignalWhat you should see
Sine 1 kHz / 100 Hz / 10 kHzA strong peak at that frequency
SweepA tone that moves up through the range
White NoiseEnergy spread across frequencies (brighter at high frequencies on a log axis)
Pink NoiseA flatter-looking spectrum on the log frequency axis
Multi-toneSeveral simultaneous peaks

Audio Input

Physical input devices: built-in microphone, USB microphones, and audio interfaces. Sample rate is shown next to the device name. This path requires Microphone permission.

If a device is unplugged while it is selected, Spectrum reports that the input disconnected and falls back to another device or to the 1 kHz test signal.

System Audio

Captures a mix of what the Mac is playing. Requires Screen Recording permission even though no video is captured. After you grant access, quit Spectrum and open it again if the plot is still silent, then play music or a video.

Applications

The Input menu lists applications that are currently playing sound. Apps that are idle are omitted, and the list is refreshed every time you open the menu. Choose an app to analyze only that app’s output. This also requires Screen Recording permission so Spectrum can hear the audio, not so it can view the app’s windows.

When the source is Music or Spotify, Spectrum shows the current song by artist (for example, Nightcall by Kavinsky) next to the Play, Stop, Next, and Previous buttons in the header, and in the window title as Spectrum - Spotify playing song by artist or Spectrum - Apple Music playing song by artist. Both update when the track changes. The first time you use those buttons, macOS asks for Automation permission for that app. Spectrum still does not record the screen. Song or artist can be missing for some streamed Music tracks; the buttons still work.

If playback is paused or the selected source otherwise goes silent, the header shows Stopped in red. The live bars clear and the peak-hold markers fall to the floor, then the plot rests. Spectrum keeps listening and returns to Running when audio starts again.

Sources with two channels can show separate left and right spectra. Use Show stereo spectrum next to the frequency range on the control bar. The switch is hidden for mono sources, including test signals.

Settings > Audio

The Audio tab shows permission status, links to System Settings, and optional analyzer presets (Speech, Music, Detailed, Low CPU). Source selection is still done from the main window Input menu.
